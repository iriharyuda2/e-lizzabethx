Random number generators (RNGs) produce numbers that appear random.

Pseudorandom

Most RNGs are deterministic algorithms seeded with a value.

Cryptographic Random

Uses physical entropy — suitable for security.

Browser API

Math.random() is pseudorandom; crypto.getRandomValues() is cryptographic.

Generate Instantly

Use a browser-based tool — no data sent anywhere.

FAQ

Is Math.random() secure?

No — don't use it for passwords or tokens.

What is a seed?

The starting value that determines the sequence.
