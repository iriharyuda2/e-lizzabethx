Base64 turns binary data into text using 64 characters.

How It Works

Every 3 bytes → 4 Base64 characters.

Alphabet

A–Z, a–z, 0–9, +, / (and = for padding).

Uses

  • Data URIs
  • Email attachments
  • API tokens

Encode Instantly

Use a browser-based tool — no data sent anywhere.

FAQ

Is Base64 smaller?

No — it's ~33% larger.

Is Base64 secure?

No — it's not encryption.
