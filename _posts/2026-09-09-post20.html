HTML entities represent special characters that would otherwise be interpreted as HTML.

Common Entities

  • &lt; = <
  • &gt; = >
  • &amp; = &
  • &nbsp; = non-breaking space

When to Use

When displaying code, special symbols, or reserved characters.

Encode Instantly

Use a browser-based tool — no data sent anywhere.

FAQ

Do I need to encode everything?

No — only characters that conflict with HTML syntax.

What's the difference between named and numeric entities?

Named use names (&lt;), numeric use codes (&#60;).
