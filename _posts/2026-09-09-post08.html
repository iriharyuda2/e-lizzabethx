A hash function turns data into a fixed-size fingerprint.

Properties

  • Deterministic
  • Fast
  • One-way (irreversible)
  • Avalanche effect

Common Algorithms

MD5 (broken), SHA-1 (weak), SHA-256 (secure).

Uses

  • Password storage
  • Data integrity
  • Digital signatures
