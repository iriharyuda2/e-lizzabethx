JSON (JavaScript Object Notation) is a lightweight data format.

Structure

Objects {}, arrays [], key-value pairs, strings, numbers, booleans, null.

Example

{"name": "Alice", "age": 30, "hobbies": ["reading", "coding"]}

Formatting

Pretty-printed JSON is easier to read; minified JSON is smaller.

Format Instantly

Use a browser-based tool — no data sent anywhere.

FAQ

Can JSON have comments?

No — use JSON5 or JSONC if you need comments.

What's the difference between JSON and JavaScript objects?

JSON is a string format; JavaScript objects are in-memory data.
